# Code of Conduct

We are committed to providing a friendly, safe, and welcoming environment for all. We expect contributors to be respectful and constructive.

- Be kind and professional.
- Assume good intent.
- No harassment or discrimination.
- Respect differing viewpoints and experiences.
- Accept constructive feedback gracefully.

If you experience or witness unacceptable behavior, please report it to the maintainers via the contact listed in `SECURITY.md` or repository issues (if appropriate).

The maintainers may take any action they deem necessary, including warnings or removal of contributions, to uphold this Code of Conduct.

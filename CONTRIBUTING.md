# Contributing to MovieVerse

Thanks for your interest in contributing! Here’s how to help effectively.

## Getting Started
- Ensure you can run the app locally: `npm install` then `npm run start`.
- Create a new branch for your change: `feat/your-feature` or `fix/your-bug`.

## Development Guidelines
- Keep changes focused and minimal.
- Follow the existing TypeScript and component patterns.
- Run linting before submitting: `npm run lint`.
- Write clear commit messages.

## Pull Requests
- Describe the problem and solution clearly.
- Include screenshots or recordings for UI changes.
- Link related issues.
- Ensure PR is rebased on `main`.

## Reporting Bugs
Use the Bug Report issue template and include:
- Steps to reproduce
- Expected vs actual behavior
- Logs or screenshots
- Environment details (OS, emulator/simulator, Expo SDK)

## Suggesting Features
Use the Feature Request template and include:
- Motivation and user story
- Proposed solution and alternatives
- Any mockups or references

## Code of Conduct
By participating, you agree to uphold our `CODE_OF_CONDUCT.md`.

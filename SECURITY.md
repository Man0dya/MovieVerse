# Security Policy

## Supported Versions
This project is maintained on the `main` branch. Security fixes are prioritized for the latest release.

## Reporting a Vulnerability
Please report security issues privately:
- Email: [ENTER SECURITY CONTACT EMAIL]
- Or open a confidential issue if your workflow supports it.

Provide as much detail as possible:
- Affected area and impact
- Steps to reproduce
- Proof-of-concept (if available)

We will acknowledge receipt within 5 business days and work on a fix or mitigation timeline.

## Disclosure
We favor responsible disclosure. Please do not publicly post details until a fix or mitigation is available.
